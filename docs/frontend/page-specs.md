# 前端页面规格

本文档同时保留目标规格和当前实现说明。目标规格不等于已经通过生产验收；当前证据和外部能力边界以[前端实现状态](./implementation-status.md)为准。

## 1. 今日工作台

目标：只展示今天必须处理的事项，不做泛化数据大屏。

### 页面区域

- 今日待发布。
- 待审核脚本/内容。
- 发布后待录入数据。
- 24 小时/7 天待复盘。
- 失败或等待人工处理的任务。
- 最近检测到的 T3/T2 爆款。

### 主要操作

- 继续写脚本。
- 审核通过。
- 打开发布包。
- 标记已发布。
- 填写复盘数据。
- 重试失败任务。

### 对应接口

```text
GET /dashboard/today
GET /jobs
```

阶段：P2。

当前实现：已接入 `/dashboard/today`，展示今日截止项目、今日发布计划、待复盘数量和活动任务数量，并提供项目、排期、复盘和任务中心入口。最近 T3/T2 内容仍在研究页面查看，尚未聚合进今日接口。

## 2. 自有账号与定位

目标：定义“为谁做、做什么、怎么说、不能说什么”，供选题和 AI 生成使用。

### 列表

- 平台。
- 账号名。
- 定位摘要。
- 内容支柱。
- 发布模式。
- 活跃状态。

### 详情

- 目标受众。
- 用户问题。
- 内容支柱。
- 语气和表达规则。
- 禁区和事实核查要求。
- 发布频率。
- 平台差异规则。
- 最近内容表现。

### 对应接口

```text
GET/POST/PATCH /owned-channels
GET/PUT /owned-channels/{id}/positioning
```

阶段：P2。

当前实现：账号列表、创建、定位详情与定位保存已完成。受众使用结构化 JSON 编辑，内容支柱、语气规则和禁区按行编辑。发布频率、平台差异规则和最近内容表现尚无当前 DTO 字段。

## 3. 对标账号

目标：管理监控对象并清楚看到同步状态，而不是只展示账号资料。

### 列表列

- 头像、昵称、平台。
- 粉丝数。
- 优先级。
- 扫描策略。
- 最近同步。
- 下次同步。
- 同步状态。
- 最近作品数。
- 最近 T1/T2/T3 数。

### 筛选

- 平台。
- 活跃/暂停。
- 同步正常/失败。
- 优先级。
- 最近同步时间。

### 操作

- 新建。
- 批量导入。
- 编辑。
- 立即同步。
- 暂停/恢复。
- 打开账号详情。

### 账号详情

- 资料和粉丝快照趋势。
- 最近作品。
- 爆款分布。
- 同步历史。
- 分页游标/接口异常只放在诊断区，不作为主内容。

### P0 后端接口

```text
GET/POST/PATCH /tracked-profiles
GET /tracked-profiles/{id}
POST /tracked-profiles/{id}/sync
POST /tracked-profiles/{id}/pause
POST /tracked-profiles/{id}/resume
GET /jobs
GET /jobs/{id}
```

### 交互要求

- “同步”返回 202 后立即显示 Job，不伪装为同步完成。
- 重复同步返回已有 Job 时，打开该 Job。
- Pause/Resume 成功后使列表和详情缓存同时失效。
- Viewer 不显示同步和编辑按钮。

阶段：列表 P0，详情数据 P1。

## 4. 灵感库

目标：统一管理对标内容、搜索发现和人工导入，并转成可执行选题。

### 页面结构

```text
Page Header
├── 统计：对标账号 / 灵感数 / 已拆解 / 待处理
├── 导入单条内容
└── 导入对标账号

Source Tabs
├── 灵感内容
└── 对标账号

Filter Panel
├── 搜索
├── 平台/账号/分类/发布时间
├── 全部/已有原稿/待转写
└── 全部/已拆框架/待拆框架

Topic Cloud

Content Area
├── Card View
└── Table View
```

### 内容卡片

- 封面。
- 平台与发布日期。
- 作者和粉丝快照。
- 标题/正文摘要。
- 点赞、评论、收藏、分享；不支持的指标显示 `—`，不能显示 `0`。
- 爆款等级。
- 分类和标签。
- L1/L2/逐字稿状态。
- 最近刷新时间。

### 批量操作

- 加标签。
- 改分类。
- 创建 L1。
- 创建转写。
- 转成候选选题。
- 归档。

高成本批量操作先展示预计调用数量和费用。

### 详情页

分区：

1. 原始内容与媒体。
2. 指标快照。
3. 爆款评分和冻结证据。
4. 评论样本。
5. 逐字稿。
6. L1/L2 分析。
7. 可复用模式。
8. 转成选题。

阶段：P1。

## 5. 搜索与热榜

目标：主动寻找新增灵感，不与已入库内容混淆。

### 搜索

- 平台。
- 关键词。
- 页数上限。
- 详情增强 Top N。
- 预计费用。

### 结果

- 首先展示摘要。
- 明确标记“已在灵感库”。
- 用户选择后才导入详情。
- 支持整页导入但必须二次确认费用。

### 热榜

- 平台与榜单类型。
- 刷新时间。
- 上升趋势。
- 关联内容。

阶段：P1。

## 6. 选题

目标：把灵感转成面向特定自有账号的内容决策。

### 视图

- Inbox。
- 已选中。
- 已拒绝。
- 已归档。

### 选题卡

- 标题。
- 目标账号。
- 受众问题。
- 切入角度。
- 钩子。
- 时效/长青。
- 来源灵感。
- 证据强度。
- 状态。

### 操作

- 从灵感创建。
- 编辑。
- 合并重复选题。
- 创建内容项目。
- 拒绝并记录原因。

阶段：P2。

当前实现：列表、URL 搜索/状态筛选、保存视图、批量进入生产/拒绝/归档、创建和详情编辑已完成；支持从详情创建内容项目。合并重复选题、时效字段、证据强度和结构化拒绝原因仍无当前 API 契约。

## 7. 内容项目与脚本

### 项目概览

- 当前状态。
- 负责人。
- 截止时间。
- 目标账号。
- 来源选题。
- 素材完成度。
- 审核状态。
- 排期。

### 脚本页

布局：

```text
左：来源与结构
中：脚本编辑器
右：版本、AI 建议、事实核查和平台约束
```

要求：

- 保存产生新版本，不覆盖旧版本。
- 清楚标记人工版本和 AI 生成版本。
- 可比较两个版本。
- 冲突返回 409 时不丢失本地内容，提供复制和重新载入。
- AI 生成前显示模型、预计用途和来源范围。
- L2 拆解只能作为参考，不能无来源复制原文。

阶段：P2。

当前实现：项目列表、状态筛选、保存视图、项目概览和状态机推进已完成。脚本页提供版本列表、人工/AI 标识、追加版本、冲突保稿与复制、AI 异步 Job 提交。双版本并排 Diff、生成前费用估算和模型选择尚未实现。

## 8. 素材库

目标：管理自有素材和引用素材的权利边界。

### 信息

- 缩略图。
- 文件类型与大小。
- 所属项目。
- 来源：上传/生成/参考。
- 授权说明。
- 创建时间。
- 使用次数。

### 上传流程

```text
申请 upload intent
→ 浏览器直传对象存储
→ 后端 complete
→ 显示处理状态
```

不得经 Next.js Server 或浏览器内存转发大型文件。

阶段：P2。

当前实现：全局素材库和项目素材页已完成，按 MIME 推断素材类型，强制填写授权说明，并执行浏览器对象存储直传。缩略图、使用次数、可取消进度条和重复上传恢复仍未实现。

## 9. 排期

### 视图

- 周视图。
- 月视图。
- 列表视图。

### 卡片

- 账号/平台。
- 内容项目。
- 计划时间。
- 审核状态。
- 发布模式。
- 冲突或缺失素材提示。

### 拖拽

- 拖拽后先发送版本化更新。
- 后端成功后确认位置。
- 409 冲突时回滚并提示刷新。
- 未审核内容不能进入可发布状态。

阶段：P2。

当前实现：按日期分组的列表视图、新建排期、审核通过、发布包和发布登记已完成。当前没有周/月视图、拖拽改期和冲突回滚 UI；排期状态由后端状态机最终校验。

## 10. 发布包与发布记录

发布包包含：

- 标题。
- 正文。
- 话题。
- 封面。
- 媒体。
- 发布时间。
- 平台注意事项。
- 复制按钮和素材下载。

MVP 中用户在平台端人工发布，再填写：

- 发布链接。
- 实际发布时间。
- 平台内容 ID（可选）。
- 是否与发布包一致。

前端不得在没有后端记录的情况下显示“已发布”。

阶段：P2。

当前实现：发布包在排期页弹窗内生成，支持复制脚本、查看平台字段和素材清单，并登记公开 HTTPS URL、平台内容 ID、实际时间和是否与发布包一致。没有独立发布记录页面。

## 11. 复盘

### 列表

- 24 小时、7 天、30 天待复盘。
- 按账号、平台和内容类型筛选。
- 是否完成。

### 详情

- 指标变化。
- 相对账号基线。
- 与预期假设对比。
- 哪些钩子/结构有效。
- 哪些不可复用。
- 下一次实验。
- 可沉淀模式。

“高播放”不能自动等同于“高转化”；页面必须把曝光、互动和业务转化分开。

阶段：P2。

当前实现：30 天表现总览、曝光/互动/转化分组、发布记录详情，以及 24h/7d/30d/manual 追加复盘已完成。账号/平台筛选、自动基线图表和“沉淀为模式”快捷操作尚未实现。

## 12. 可复用模式

目标：沉淀经过验证的钩子、结构、选题和表达模式。

状态：

- Draft。
- Validated。
- Retired。

详情必须显示：

- 来源内容。
- 证据。
- 适用账号。
- 成功次数和失败次数。
- 不适用条件。

阶段：P1/P2。

## 13. 任务中心

### 全局入口

顶部显示：

- 运行中数量。
- 失败数量。
- 预算阻止数量。

### 任务详情

- 类型。
- 来源页面。
- 状态。
- 进度。
- 尝试次数。
- 创建、开始、完成时间。
- 可重试时间。
- 去敏错误。
- Request ID。
- 重试/取消。

状态映射：

| 后端状态 | UI |
|---|---|
| `pending` | 排队中 |
| `running` | 处理中 |
| `retry_wait` | 等待重试 |
| `succeeded` | 已完成 |
| `failed` | 失败 |
| `dead` | 需人工处理 |
| `cancelled` | 已取消 |

阶段：P0。

## 14. 用量与费用

按日展示：

- TikHub 调用量和费用。
- AI L1/L2 Token 与费用。
- ASR 时长与费用。
- 缓存命中率。
- 预算使用比例。

达到 70%、90%、100% 使用明显但不恐慌的提示。100% 时说明哪些任务会停止、哪些站内功能仍可用。

阶段：P1。

## 15. 设置

分区：

- 工作区。
- 成员和权限。
- 默认时区。
- TikHub/AI/ASR 连接状态，只显示是否配置，不显示 Secret。
- 扫描策略。
- 评分策略。
- 预算。
- 数据保留。
- 危险操作。

危险操作使用独立区域、明确目标和二次确认。

阶段：基础 P0，其余 P1/P2。

## 16. P3 效率增强

### 跨实体搜索与命令

- `Command/Ctrl + K` 打开命令面板。
- 搜索灵感、模式、选题和内容项目。
- 展示实体类型、匹配摘要和匹配字段。
- 仅展示当前角色可执行的写命令。

当前实现是可解释关键词搜索，不是向量语义搜索。

### 保存视图与批量操作

- 选题、内容项目、排期和复盘页面支持保存当前 URL 筛选。
- 当前前端可创建个人视图，并可读取后端返回的团队共享视图；创建/修改共享状态的 UI 尚未提供。
- 选题支持批量进入生产、拒绝和归档。
- 批量写入仍由后端逐项进行版本校验。

### 运营实验与协作

- 运营实验记录可证伪假设、主指标、版本和冻结版本号。
- 项目负责人、共享视图和实验分组构成当前协作信息。
- 独立通知中心和真实消息投递尚无前端/后端闭环。

### 移动端

- Drawer 导航。
- 查看任务、项目、排期和复盘。
- 快速审核发布计划。
- 登记发布结果和复盘指标。

复杂脚本编辑、批量操作和排期管理仍以桌面端为主。

阶段：P3。当前后端契约支持的部分已实现。
